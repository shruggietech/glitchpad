# Glitchpad components

GENERATED by `build/gen_vanilla.py` from `brand.json`. Regenerate rather than editing.

These framework-light React components carry the Glitchpad interface grammar for mocks and
non-React surfaces. Import `../styles.css` and `components.css`, then compose the JSX
modules. Every visual value resolves through the `--gl-*` token namespace, so there is
no raw hex and no raw px anywhere in this directory.

Core covers Button, Badge, Card, Divider and SectionHeading, plus one row component per
entry in `domain_components`. Form components expose a visible label, required state and
an accessible error message. Status is carried by a dot or a text label as well as colour.
