# Glitchpad concept exploration, round 01

These images are ideation references only. They are not approved or shippable logo artwork. Any selected direction must be reconstructed as hand-authored filled-path SVG geometry on a declared square grid under the ShruggieTech logo protocol.

The constant palette across all three boards is intentional. Geometry and character are being evaluated separately from the identity-accent decision.

## 01. Ghost Pane

```text
Use case: logo-brand
Asset type: Glitchpad brand-mark ideation board, concept only
Primary request: Explore an original "Ghost Pane" symbol for Glitchpad, a quiet technical file viewer. Build the mark from nested rectangular viewing panes, a deliberately open edge, one clipped terminal, and negative space that subtly suggests a lowercase g without becoming a literal letter. Let the outer rails faintly echo the bilateral bracket-like balance of a larger family identity, but do not draw a face or emoticon.
Style/medium: flat vector logo exploration, minimalist geometric construction, strong silhouette, cyberpunk reimagining of a retro-futurist wrist-computer display
Composition/framing: one large hero mark centered, with three smaller related silhouette variations arranged beneath it; generous margins; subtle square construction grid only in the background
Lighting/mood: silent, precise, covert, black-glass instrument, calm menace
Color palette: near-black and smoked graphite with one sparse sulfur-phosphor yellow accent; flat inks only
Materials/textures: no material rendering inside the marks; extremely faint CRT grain may appear in the background board only
Constraints: original geometry; vector-friendly filled shapes; readable at favicon scale; no words, captions, letters, numbers, UI labels, watermark, gradients, glow, 3D, mockup devices, skulls, weapons, shields, eyes, crosshairs, scan lines, RGB glitch effects, or Fallout-specific symbols
```

## 02. Black Terminal

```text
Use case: logo-brand
Asset type: Glitchpad brand-mark ideation board, concept only
Primary request: Explore an original "Black Terminal" symbol for Glitchpad. Distill the physical logic of a retro atomic-age wrist terminal reimagined as compact cyberpunk equipment into an abstract file-viewer mark: a heavy protective outer frame, a recessed black pane, a single file corner or page notch, and one decisive asymmetric cut suggesting fast inspection. The result must feel like a covert instrument, not a gadget illustration.
Style/medium: flat vector logo exploration, severe industrial geometry softened by a few controlled rounded corners, minimalist, technical, scalable
Composition/framing: one large hero mark centered, with three reduced-mark variants beneath it showing progressive simplification; generous margins; faint construction grid in the background
Lighting/mood: silent and deadly, utilitarian, clandestine field hardware, worn-in concept but visually clean
Color palette: near-black, charcoal, warm off-white, with one sparse sulfur-phosphor yellow accent; flat inks only
Materials/textures: marks remain pure flat shapes; board may carry almost imperceptible aged-screen speckle
Constraints: original geometry; vector-friendly filled paths; distinct silhouette at 16-32 px; no words, captions, letters, numbers, UI labels, watermark, gradients, glow, 3D, literal wrist device, people, skulls, weapons, shields, eyes, crosshairs, scan lines, RGB glitch effects, or Fallout-specific symbols
```

## 03. Dead Pixel Aperture

```text
Use case: logo-brand
Asset type: Glitchpad brand-mark ideation board, concept only
Primary request: Explore an original "Dead Pixel Aperture" symbol for Glitchpad, a file viewer that reveals what is normally hidden. Construct a calm square or rounded-square viewing aperture from a sparse pixel grid, remove one strategically important cell, and use the missing cell plus an offset document plane to create a ghost-like absence. The personality should come from omission and negative space, never from a mascot.
Style/medium: flat vector logo exploration, minimalist modular geometry, forensic cyberpunk, quiet and intelligent
Composition/framing: one large hero mark centered, with three small alternate silhouettes below; generous margins; faint modular construction grid in background
Lighting/mood: controlled anomaly, invisible observer, precise and unsettling
Color palette: near-black and smoked graphite with one sparse sulfur-phosphor yellow accent and optional warm off-white; flat inks only
Materials/textures: no texture inside marks; nearly invisible CRT grain on board background only
Constraints: original geometry; vector-friendly filled shapes; reduced version must survive favicon scale by dropping whole modules; no words, captions, letters, numbers, UI labels, watermark, gradients, glow, 3D, mascot face, skulls, weapons, shields, eyes, crosshairs, scan lines, RGB glitch effects, or Fallout-specific symbols
```
