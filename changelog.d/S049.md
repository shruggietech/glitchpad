# S049: PDF viewer foundation

Added unreleased local PDF reading with a pinned isolated PDF.js worker, bounded source ranges and Android private stream caching, virtualized pages, selectable text, fit/zoom/rotation, page navigation, search, outline, thumbnails, explicit links and PDF metadata. Added bounded selected/all-page print snapshots with native desktop handoff and an Android system print adapter.

PDF scripts, document actions, editable forms, attachment launch and automatic external resources are not activated. This slice does not add stable PDF file associations or publish a release.
