# Glitchpad v0.1.0 Community Release

Glitchpad v0.1.0 is the first installable community release. It provides local Markdown and Mermaid viewing and editing, plain-text and supported source editing, compact document tabs, metadata inspection, recovery, native desktop file delivery, and Android document intents. Files remain local; Glitchpad has no account, cloud synchronization, or telemetry service.

## Downloads

- Windows 11 x86_64: NSIS installer and portable ZIP.
- macOS 13+: universal DMG for Apple Silicon and Intel.
- Linux x86_64: AppImage and Debian package, built against Ubuntu 22.04.
- Android 7.0+: universal APK, ARM64 APK, and AAB.

## Trust and installation

Windows packages are unsigned community artifacts and may trigger Microsoft Defender SmartScreen. Verify the SHA-256 checksum from this release, then use the ordinary per-application Windows approval control if you choose to run it. Do not disable SmartScreen globally.

The macOS application uses an ad-hoc signature and the DMG is not notarized by Apple. Verify its SHA-256 checksum, then use the ordinary Open Anyway control for this application if macOS blocks first launch. Do not disable Gatekeeper globally.

Linux artifacts carry GitHub repository-bound attestations. Android artifacts are signed with the stable project-owned update key; verify the published certificate fingerprint before sideloading.

## Integrity evidence

Every package family includes final-byte checksums, a CycloneDX SBOM, provenance, Apache-2.0 license material, notices, source revision, version, and machine-readable trust evidence. Download only from the official GitHub release page and compare the artifact SHA-256 before installation.

## Known limits and feedback

Image, PDF, DOCX, and ODT viewing are planned for later releases and are not supported in v0.1.0. Manual accessibility, physical-device, platform-polish, and real-world validation begins after publication under issue #66. Defects reported after this first release will be handled before v0.2 feature development.
