# Glitchpad v0.1.1 behavior delta

S027 is the content-first corrective hotfix for the initial v0.1.0 desktop release. It removes synthetic demonstration documents and fake recovery state from production startup, restores direct TXT and Markdown visibility, hides the tab strip until two documents are open, gives every visible tab its own close control, replaces permanent command rows with a compact application menu, integrates editor search styling, and strengthens the packaged Windows smoke gate around the real first-run workflow.
