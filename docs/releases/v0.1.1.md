# Glitchpad v0.1.1 Corrective Release

Glitchpad v0.1.1 is the corrective successor to the initial community release. It keeps the same local-first Markdown, Mermaid, plain-text, and supported-source capabilities while fixing the application shell so the requested document owns the viewport.

## What changed

- A normal launch starts empty instead of opening synthetic demonstration documents.
- Opening a TXT, Markdown, Mermaid, or supported source file displays the requested content immediately.
- The tab strip appears only when at least two documents are open, and every visible tab has its own close control.
- A compact application menu replaces the crowded always-visible command rows.
- Outline, print, search, file information, and secondary panels now appear only when relevant to the active document.
- Packaged Windows smoke coverage verifies launch, native file-open delivery, and visible document content.

## Downloads

- Windows 11 x86_64: NSIS installer and portable ZIP.
- macOS 13+: universal DMG for Apple Silicon and Intel.
- Linux x86_64: AppImage and Debian package, built against Ubuntu 22.04.
- Android 7.0+: universal APK, ARM64 APK, and AAB.

## Trust and installation

Windows packages are unsigned community artifacts and may trigger Microsoft Defender SmartScreen. Verify the SHA-256 checksum from this release, then use the ordinary per-application Windows approval control if you choose to run it. Do not disable SmartScreen globally.

The macOS application uses an ad-hoc signature and the DMG is not notarized by Apple. Verify its SHA-256 checksum, then use the ordinary Open Anyway control for this application if macOS blocks first launch. Do not disable Gatekeeper globally.

Linux artifacts carry GitHub repository-bound attestations. Android artifacts are signed with the same stable project-owned update key as v0.1.0 so existing installations can upgrade; verify the published certificate fingerprint before sideloading.

## Integrity evidence

Every package family includes final-byte checksums, a CycloneDX SBOM, provenance, Apache-2.0 license material, notices, source revision, version, and machine-readable trust evidence. Download only from the official GitHub release page and compare the artifact SHA-256 before installation.

## Known limits and feedback

Image, PDF, DOCX, and ODT viewing remain planned for later releases and are not supported in v0.1.1. Manual accessibility, physical-device, platform-polish, and real-world validation remains post-release work under issue #66. Report defects through the project issue tracker so they can be addressed before v0.2 feature development.
