# Glitchpad v0.1.3 Corrective Release

Glitchpad v0.1.3 is the third corrective release following v0.1.0. It packages the practical-use repairs from S035, the sectioned specification documentation from S036, the post-merge automation from S037, and the exact-package evidence and release reconciliation from S038 without broadening the stable format matrix.

## What changed

- S035 (#171) keeps Markdown usable across every supported opening path, including native file-association delivery, even when preview rendering fails.
- Markdown results remain scoped to the current session, revision, and render generation, and source recovery remains available without exposing source while a preview is pending.
- S035 (#172) reserves shell chrome so the compact application menu, document controls, and scrollable content no longer overlap.
- Desktop candidate workflows record content-free practical-use receipts that bind successful installed or clean-host checks to the exact package manifest and reviewed source revision.
- Release assembly refuses missing, duplicated, stale, content-bearing, or failed practical-use evidence.
- Public technical documentation is split into navigable section pages generated from one normative specification source.
- Post-merge documentation publication and merged-branch cleanup are automated with explicit concurrency, provenance, and failure reporting.

## Issue traceability

- #171: prevent universal Markdown preview failure across native and in-app open paths.
- #172: reserve shell chrome and eliminate application-menu overlap.
- #66: perform post-release manual and physical-device validation (remains open and is not claimed by this release).

## Packages and platforms

The official release contains eight application packages: an unsigned Windows NSIS installer and portable ZIP, a universal macOS DMG with an ad-hoc signature that is not notarized, Linux AppImage and Debian packages with repository attestations, and Android universal APK, ARM64 APK, and AAB packages signed by the stable project-owned update key. Windows SmartScreen and macOS Gatekeeper may warn because this zero-cost community release does not use paid platform trust programs.

Each package is accompanied by SHA-256 checksums, software-bill-of-materials data, provenance, license notices, the reviewed source revision, and machine-readable trust evidence. Desktop release assembly additionally requires practical-use receipts bound to the exact candidate package manifest. Android retains API 24 and API 36 provider-backed delivery evidence and exact release-package inspection.

## Supported capabilities and limits

Glitchpad v0.1.3 supports local Markdown, Mermaid, plain-text, and recognized source files with the released view, edit, save, search, inspection, recovery, and compact multi-document behaviors. Image, PDF, DOCX, and ODT support remains planned for later releases and is not included here. The application has no account, telemetry, or file-content network dependency. Remote document resources remain blocked.

## Installation and feedback

Download packages only from the official GitHub release, verify `SHA256SUMS`, and review the platform trust evidence before installation. Report defects through the repository issue tracker. Manual real-world validation remains post-release work tracked by issue #66.
