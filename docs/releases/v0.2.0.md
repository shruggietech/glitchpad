# Glitchpad v0.2.0 image activation candidate

S043 qualifies and activates bounded PNG, JPEG, WebP, BMP, TIFF, GIF, SVG and ICO viewing, inspection and existing selected ICO-entry PNG export. It retains the S042 BrandBuilder kit and AppFrame shell. Source image editing, PDF, DOCX and ODT support remain outside this release.

Image controls include fit, zoom, pan, pause/frame navigation and independent ICO entries. Metadata includes EXIF/XMP/IPTC and color/provenance facts with explicit sensitive-location reveal. Malformed/oversized inputs receive bounded refusal; SVG scripts and external resources never execute. Image source bytes remain unchanged by viewing and selected-entry export.

Issue #75 owns image conformance; #76 owns final activation/publication. This candidate does not close their publication-dependent obligations. Core evidence is tracked by issue #66. Under the owner's 2026-11-02 decision, physical-device and manual screen-reader checks are unavailable and are not required gates. Automated accessibility, hosted native source/provider checks and package lifecycle evidence remain required. Neither removed evidence class is claimed.

The eight final packages retain the community trust model: Windows is unsigned, macOS uses an ad-hoc application signature and is not notarized, Linux is repository-attested, and Android uses the stable project-owned update key. Verify SHA-256 against SHA256SUMS, package SBOM, provenance and notices. No package is official until the reviewed release is tagged, published and independently read back.
