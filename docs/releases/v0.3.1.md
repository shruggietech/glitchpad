# Glitchpad v0.3.1

v0.3.1 is a maintenance release for the S049/S050 PDF foundation. It includes the dependency convergence in #265 and #267, SHA-2 integrity encoding compatibility, fallible native memory sampling, preserved Android task and native printing contracts, refreshed dependency notices, and bounded test-readiness fixes. PDF viewing, search, navigation, metadata and system printing remain available alongside the existing text and image families.

Windows packages are unsigned. macOS is ad-hoc signed and not notarized. Linux retains repository attestations, and Android retains the stable project signer. Verify SHA-256 values against SHA256SUMS and community-release-manifest.json.

The v0.3.0 gates #81, #82 and #11 are complete and are retained as lineage. Physical-device, manual screen-reader and reference-hardware limitations remain as previously recorded in issue #66. Issue #239 retains its separate scope. No new physical-device or manual VoiceOver claim is made by this release.
