# Original image-family corpus

These fixtures are original synthetic artwork created by Glitchpad contributors and distributed under the repository's Apache-2.0 license. No camera photograph, third-party image, location, or personal metadata is included. `manifest.json` records encoded byte lengths and SHA-256 digests.

Regenerate from the repository root with `cargo run -p glitchpad-core --example generate_image_fixtures`. The original 13 raster fixtures retain their S039 digests. The generator adds a four-frame GIF with previous/background disposal and transparency, a two-frame lossless animated WebP with alpha, an inert SVG with bundled-font text, an SVG that must be refused, and an ICO containing PNG, DIB, duplicate, and corrupt entries. Every canvas is 4 by 3 pixels; the eight JPEG variants carry each standard EXIF orientation. Tests construct additional bounded metadata, malformed headers, thumbnails, and hostile blocks in memory. Source markup is never inserted into the browser DOM.
