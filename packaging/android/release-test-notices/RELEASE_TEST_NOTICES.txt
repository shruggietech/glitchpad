Kotlin stdlib and AndroidX tracing classes in the release test package have their namespaces relocated to com.shruggietech.glitchpad.testisolated so external test callers cannot borrow app-optimized library ABIs. This transformation applies only to test code and its copied runtimes. It changes binary namespaces; the canonical product APK and its keep rules are unchanged.
