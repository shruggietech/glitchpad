Glitchpad is a focused, local-first desktop and Android viewer and editor for common files. It is currently at version 0.0.0, with no installable release or production viewer available yet.

## Start with the technical specification

The [technical specification](/docs/technical-specification) is the normative authority for architecture, product behavior, security, platform support, file-format capability, validation, and release requirements. The public copy is generated from `docs/glitchpad-technical-specification.md` during every site build so repository documentation remains authoritative.

## Development status

The repository currently provides the buildable application foundation, shared verification tooling, and desktop and Android host scaffolding. Capability claims remain planned until their specification, implementation, tests, and platform evidence land together.

For contribution requirements, source code, and current work, visit the [Glitchpad repository](https://github.com/ShruggieTech/glitchpad).
