# Contract: Public Repository Foundation

**Date**: 2026-08-30

## Required root authorities

The initial commit MUST contain `README.md`, `LICENSE`, `NOTICE`, `CHANGELOG.md`, `CONTRIBUTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md`, `AGENTS.md`, `Cargo.toml`, `Cargo.lock`, `rust-toolchain.toml`, `package.json`, `pnpm-lock.yaml`, `pnpm-workspace.yaml`, `.node-version`, `.gitattributes`, `.gitignore`, `.editorconfig`, Prettier and markdownlint configuration, and the durable `.specify`, `docs`, and `specs` content.

## Public claim contract

- v0.0.0 is repository foundation and has no application binaries.
- Planned viewers are roadmap items until their support rows become stable.
- Windows, macOS, Linux, and Android are target families, not current download claims.
- Apache-2.0 applies to project source and original distributable assets.
- The final public path is `ShruggieTech/glitchpad`.
- No old project, old website, migration, or temporary-brand narrative appears.

## Git contract

- Initial branch is `main`.
- Initial history contains one commit after this slice.
- The existing local Git identity is used unchanged.
- No remote is configured.
- `.specify/feature.json`, dependencies, outputs, caches, local SDK paths, signing material, secrets, and IDE state are not tracked.
- Text normalization follows `.gitattributes`; required Windows command scripts may retain CRLF.

## Community-health contract

The repository provides contribution, security, conduct, pull-request, issue, ownership, dependency-update, and support-routing documents. Security reports use private disclosure instructions rather than public issues. Templates request reproducible evidence without demanding private document content.
