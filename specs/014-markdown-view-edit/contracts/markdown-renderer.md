# Markdown Renderer Contract

## Purpose

This contract defines the platform-independent boundary between a Markdown document session and its local parser/sanitizer. The source remains owned by `TextDocumentState`; render results are disposable projections.

## Eligibility

| Encoded source size | Contract behavior |
| --- | --- |
| 0 through 16 MiB | Rendered and source modes; rendered is default. |
| Greater than 16 MiB through 32 MiB | Source mode only; preview reports `limited`. |
| Greater than 32 MiB through 256 MiB | Existing source-backed large-text view. |
| Greater than 256 MiB | Existing explicit refusal. |

## Request

```text
MarkdownRenderRequest {
  requestId: string
  sessionId: string
  sourceRevision: integer
  sourceText: string
  sanitizerVersion: integer
}
```

The worker receives no source handle, path, URI, Tauri object, fetch implementation, window reference, native gateway, recovery record, or unrelated session state.

## Result

```text
MarkdownRenderResult {
  requestId: string
  sessionId: string
  sourceRevision: integer
  status: ready | empty | limited | cancelled | failed
  tree?: SafeRenderedNode
  outline: HeadingEntry[]
  searchText: SearchTextEntry[]
  diagnostics: SafeDiagnostic[]
  measurements: RenderMeasurements
  sanitizerVersion: integer
}
```

Only a result whose request, session, revision, sanitizer version, and active-client generation all match may commit. Every other result is ignored.

## Safe Output Policy

- Raw HTML nodes become text before conversion.
- Generated output is sanitized after the final transform.
- Allowed document elements are limited to paragraphs, six heading levels, emphasis, strong emphasis, deletion, quotations, ordered and unordered lists, list items, thematic breaks, breaks, code, preformatted blocks, tables and table sections/cells, footnote sections and references, and Glitchpad-owned inert link/resource controls.
- Script, style, frame, object, embed, form, input with active behavior, media, SVG, MathML, metadata, base, and unknown elements are absent.
- Event handlers, inline CSS, document IDs not generated by the renderer, `srcdoc`, refresh behavior, arbitrary ARIA, and unknown properties are absent.
- URL-bearing authored properties are classified by application policy and never copied directly into browser navigation properties.
- React rendering uses no raw HTML injection and no untrusted property spread.

## Lifecycle

One client owns at most one active request. Scheduling a newer revision cancels the timer or terminates the older worker before dispatch. `suspend` cancels work and releases the accepted tree while retaining source and mode. `dispose` is idempotent and releases every worker, timer, observer, result, and callback. Cancellation is observable within 250 ms and never produces a failure diagnostic.

## Stable Diagnostics

| Code | Meaning |
| --- | --- |
| `markdown_empty` | The source contains no rendered content. |
| `markdown_preview_limited` | Source exceeds 16 MiB but remains usable through a source path. |
| `markdown_cancelled` | Work was deliberately superseded or disposed. |
| `markdown_parse_failed` | The local pipeline failed safely. |
| `markdown_policy_mismatch` | Request and renderer sanitation versions disagree. |
| `markdown_output_limited` | Safe structural depth or count was exceeded. |

Diagnostics include a stable code and bounded user-facing message only. They exclude source excerpts, file locators, raw URLs, stack traces, and dependency internals.

## Verification

Contract tests cover syntax semantics, raw HTML preservation as text, final sanitation, remote-resource denial, link extraction, outline/source positions, deterministic search text, size limits, 100 superseded revisions, cancellation, suspension, disposal, failure redaction, and deterministic repeated output.
