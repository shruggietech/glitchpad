# Quickstart: Contextual Metadata Inspector Validation

## Automated gates

Run `cargo test -p glitchpad-core`, `cargo test -p glitchpad-host`, and `pnpm --filter @glitchpad/app test`, then run `pnpm check` and watch it through completion.

Expected result: catalog and serialization, path-free snapshots, revision matching, checksum transitions, copy policy, responsive structure, focus behavior, renderer contributions, stale rejection, formatting, lint, documentation, security, platform, encoding, and runtime checks all pass.

## End-to-end scenarios

1. Open text, Markdown, and Mermaid sessions. Invoke File information through the command bar and renderer control. Confirm one grouped nonmodal inspector, preserved document context, and opener focus restoration.
2. Exercise all six availability states and all copy policies. Confirm exact direct copy, explicit sensitive disclosure, prohibited copy denial, and no protected clipboard or announcement value.
3. Publish matching and stale host/renderer contributions while retaining dirty editor and viewport state. Confirm only matching facts update in place.
4. Hash known, empty, unknown-length, oversized, cancelled, and externally modified sources. Confirm only complete exact revisions publish a digest and every terminal path releases operation state.
5. Run desktop conformance plus API 24/36 controlled-provider evidence. Confirm omissions remain not provided, no Android URI becomes a path, and platform write state remains truthful.

## Manual receipts

- Keyboard, screen-reader, Escape, opener-focus, restrained-announcement, touch-target, and phone/tablet scrolling checks.
- Hostile-value check proving zero network, telemetry, shell, navigation, arbitrary native invocation, or unsafe markup interpretation.
