# Community Release Manifest Contract

The release contains exactly eight distributable artifacts: Windows installer and portable ZIP, macOS universal DMG, Linux AppImage and Debian package, Android universal APK, ARM64 APK, and AAB. Their canonical names include `0.1.0` and are governed by the repository release manifest. Platform manifests bind final bytes to source commit, checksum, size, SBOM, provenance, license, notices, and trust state. Missing or additional distributable artifacts fail validation.
