1. Read root `AGENTS.md`, then the pinned kit receipt and `brand/enforcement/AGENTS.md`.
2. Confirm the receipt names the expected upstream S042 revision and successful workflow artifact.
3. Run the brand manifest and governance checks through the approved hidden Docker launcher.
4. Run frontend unit and shell-layout checks through the approved hidden Docker launcher.
5. Run Android instrumentation through the existing API 24/API 36 CI jobs or approved hidden launcher.
6. Run the Windows Tauri build/package and smoke checks through the documented CI path.
7. Compare results with `verification.md`; do not substitute browser evidence for either actual host.
