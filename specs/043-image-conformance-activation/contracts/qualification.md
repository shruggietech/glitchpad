# Contract: S043 Qualification and Activation

## Inputs and outputs

Qualification accepts only repository-owned licensed/generated corpus inputs and explicit bounded mutation seeds. Outputs are classified decoder/metadata outcomes, regression inputs and machine-readable measurements. No source path, user data or runtime credential enters retained artifacts.

## Admission and disposal

Use explicit small fuzz limits for source bytes, dimensions, metadata facts, animation frames, generated PNG payload and decode budget. Every returned output must satisfy the same structural validator used by the application. Resource measurements distinguish total process RSS from budget accounting; suspended browser sessions must release decoded surfaces and stop animation work.

## Activation

Allowed extensions are `png`, `jpg`, `jpeg`, `webp`, `bmp`, `tif`, `tiff`, `gif`, `svg`, `ico`. Native handlers use exact declared MIME types and existing content detection, source identity and grant rules. Registration does not imply source image editing or arbitrary active-content execution.

## Acceptance reporting

The core matrix contains TS-FR-001 through TS-FR-023. The issue matrix contains every criterion for #66/#75/#76 with its own disposition. Each evidence class is independent. Owner-removed physical/manual checks remain disclosed as unavailable and are not blockers. Publication obligations remain pending at PR handoff.

## Review

Initial external reviews arise from PR publication. At most one explicit `@Codex` follow-up request is allowed. Every comment receives a reply or documented disposition and satisfied inline threads are resolved. The final head must finish required CI before owner handoff. No merge/tag/release is performed.
