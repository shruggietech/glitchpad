# Document Action and Native Destination Contract

## Action execution

Validate current session/revision and availability, acquire pending ownership, invoke exactly one native or renderer provider, await its performed/failed/cancelled/unavailable result, and publish only for its captured target. No missing handler or availability check can produce performed success. Menu/keyboard/local tools use the same operation methods. Clipboard Promise rejection is a failed result. Empty history and no-preview Zoom are unavailable.

## Native writes

A draft/diagnostic create operation requires no existing source. Existing-source Save As validates the source external revision first. Bound input bytes/name/MIME before picker. Cancellation is neutral. Resolve destination identity and reject source aliases/nonempty destinations before destructive open. Write, flush/sync, verify descriptor errors, bounded-read exact bytes and acquire destination before receipt. Restrict cleanup to a proven independent destination written by this operation. Receipt never cleans an unsaved newer revision.

## Diagnostic export and failure capture

Freeze one redacted serialized preview. Save reads back exact bytes and returns receipt. Share uses JSON MIME, a bounded temporary cache URI and temporary read permission; report system handoff/cancellation, not recipient delivery. Capture allowlisted component/stage/reason/correlation events from root/document/worker/delivery/action/export boundaries. Environment identity is native or explicitly unavailable.
