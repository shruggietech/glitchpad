# S047 implemented inert SVG profile

This is implementation handoff text for the root-owned feature contract. resvg/usvg remain0.48.1; direct parser edges use already-locked simplecss0.2.2 and svgtypes0.16.1. Original source bytes never reach browser SVG markup: the native host returns checked inert PNG bytes plus metadata and finite failure state.

## Admission

The bounded content probe resolves the SVG namespace with quick_xml::NsReader, so default and prefixed SVG roots identify consistently. Accepted SVG namespace element names are svg, g, defs, symbol, use, path, rect, circle, ellipse, line, polyline, polygon, text, tspan, textPath, title, desc, metadata, style, linearGradient, radialGradient, stop and clipPath. Foreign exporter metadata may occur inside SVG metadata; other foreign element namespaces refuse. Namespaced exporter attributes not interpreted by usvg are ignored. Script/event attributes, foreignObject, image embedding, links/animation and unlisted elements refuse. Expensive filter/mask/pattern/marker/cursor features remain outside this profile.

Inline style and internal text/css/default style sheets use pinned simplecss static selector/declaration parsing; presentation attributes remain supported. CSS quoted strings/comments are recognized before policy checks, so literal @ in a quoted font name/comment is not an external-resource declaration. CSS escaped identifiers/strings and at-rules are outside the presentation subset. Local @font-face is unsupported; @font-face containing an external url() is a refused resource declaration. @import is a refused resource declaration. This is the pinned renderer's presentation CSS subset, not a browser CSS engine or a guarantee for CSS variables/vendor-specific features. CSS property-value rendering follows pinned usvg semantics, including its normal fallback for invalid values.

Supported CSS presentation properties: fill, fill-opacity, fill-rule, stroke, stroke-width, stroke-opacity, stroke-linecap, stroke-linejoin, stroke-miterlimit, stroke-dasharray, stroke-dashoffset, opacity, color, display, visibility, font-family, font-size, font-style, font-weight, font-stretch, font-variant, font-kerning, text-anchor, dominant-baseline, alignment-baseline, baseline-shift, letter-spacing, word-spacing, text-decoration, writing-mode, shape-rendering, text-rendering, image-rendering, color-interpolation, color-rendering, clip-rule, clip-path, stop-color, stop-opacity, overflow, paint-order, vector-effect, direction, unicode-bidi, white-space and transform. Unknown declarations return svg_unsupported. Fonts resolve only from bundled Geist; no system font scan/network font download is introduced.

Fragment href/XLink href and functional paint/clip references use pinned svgtypes IRI/FuncIRI grammar. Unprefixed href wins over xlink:href, and the first matching ID owns a fragment, matching pinned usvg. Missing targets and self/ancestor/indirect cycles have dedicated failures. A memoized dependency/expansion graph includes children, local references and matching presentation CSS references; expansion cost/depth remains bounded conservatively by50000/128. CSS matching has a250000-comparison bound. Each selector is also limited conservatively to128 traversal components before either application or pinned converter matching. The existing CSS lexical scan respects strings/comments, attribute and pseudo-class interiors and comma-separated selector boundaries; comments outside a value may conservatively separate components. A128-component adjacent chain renders expected pixels,129 returns oversized, and more than128 relation-like characters inside quoted attribute values/comments remain accepted. All loops keep cooperative cancellation/deadline checks. External/data/file resources are rejected by preflight, and both usvg image resolver hooks independently remain closures returning None. Tree::from_xmltree receives the already parsed no-DTD document; Tree::from_str/default resolvers are not used.

## Refusal contract

- malformed: invalid XML/UTF8/converter syntax; truncated retains its existing codec meaning.
- svg_unsupported: outside declared element/CSS profile, including local font-face; no identical Retry.
- svg_external_reference: external resource or document-type/entity declaration admission refusal. This group includes a purely internal DTD; UI explicitly says requests external resources OR declares entities, never claims an observed network URL. Neither is resolved. No identical Retry.
- svg_cyclic_reference and svg_missing_reference: local dependency validation failures; no identical Retry.
- oversized/allocation/output_limit/deadline: existing resource/output/cooperative-time outcomes; no identical Retry as remedy.
- source_read/source_revoked/source_revised/source_unavailable: native source rejection, retaining fixed read-stage context/category/retryability and source information. ResourceLimit/BudgetExceeded source rejections become oversized; busy remains its existing admission/scheduling case.
- host_transport: native service invocation/rejection without a source-read classification; bounded Retry is available. invalid_result refuses an unrelated/malformed native reply; display_failed permits Retry after browser bitmap display failure.

ImageRenderResult.failure is a finite Rust enum and closed TypeScript token union. Rejected native CoreError read failures carry fixed context.image_stage=source_read without source/error payloads. ImagePreviewError stores only a fixed outcome; UI copy never projects raw exceptions. ImageDocumentState retains this outcome and independent metadata. SVG failed family state is unavailable/external_resources=false/scripts=false/max_nodes50000/max_depth128. No preview means local controls disabled and providers false. The root App owns shared menu availability. File information remains available; the UI does not invent an external file launcher or claim a revoked source is readable.
