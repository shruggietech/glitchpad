# S050 PDF activation contract

PDF is a canonical family with extension pdf, media type application/pdf, renderer pdf, association=true and dialog=true. Desktop delivery promotes it into the governed inventory. Windows/macOS/Linux generated registrations and Android content VIEW/SEND intent declarations agree. Linux references the existing system-owned MIME type instead of redefining it.

Cold/warm native acquisition must resolve/deliver real PDFs to the current source-bound viewer. Seek and stream provider paths retain grants/revision/private-cache limits. Portable Windows continues preserving global association state. DOCX/ODT, unsupported generic/file-scheme/multiple-send cases remain explicit negatives. Inventory counts are derived where possible and exact changed inventories are tested.

Only candidate source/metadata target0.3.0 changes before publication. Actual public download destinations remain the currently published authority. No additional source privileges, parser authority, usage eligibility checks or editing capabilities are added.
